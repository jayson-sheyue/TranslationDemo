最安全的学习顺序

  1. 文本翻译（NMT）
  2. 语言检测
  3. 罗马化
  4. 文档翻译（小测试文件）
  5. 术语表 → 再回文本翻译试用
  6. 自适应
  7. 批量、OCR

术语表、批量、自适应数据集需要你自己项目里的 GCS 桶。仓库 assets/ 里已有可预览的样例；部署到本地后，相关分页会自动加载文件内容，需要上传时再一键写到你填写的桶。

三件最容易踩坑的事

  • 自适应不是 TranslateText 的一个模型。不要找 general/translation-llm-adaptive，本 Demo 已从文本翻译里拿掉。
  • 术语表要先创建，再填写 ID。创建在「术语表」页；真正翻译仍在「文本翻译」。
  • 批量任务不会立即完成。只返回任务编号，稍后到 GCS 输出目录找结果。

TRANSLATETEXT

文本翻译

接口：TranslateText。只翻屏幕上的短文本。本页模型只有 NMT 和 Translation LLM。

本页不是：自适应翻译、术语表创建、文档 / 批量 / OCR。那些都有单独分页。

第一次怎么做

  1. 用默认英文短句即可；每一行会单独翻译。
  2. 源语言不知道就留空；目标语言先保留 zh-CN。
  3. 模型先选 NMT，点“翻译”。要更自然再改选 Translation LLM，用同一句话对比。
  4. HTML 样例来自仓库 assets/text/html-sample.html，点按钮即可填入。
进阶：已创建的术语表、已训练的自定义模型、结算标签

使用术语表或自定义模型时必须亲手填写源语言，例如 en。占位符不会自动提交。本 Demo 不会训练 AutoML / 自定义 TLLM，请到 Console 完成后再把模型 ID 填在上面。

打开 Translation Console AutoML 官方教程 自定义 TLLM 文档

GLOSSARY

术语表

本页只负责创建和查看术语表。真正翻译时，回到「文本翻译」，打开进阶选项，填同一个 ID。

本页不会输出译文。它也不是自适应：术语表按精确匹配锁词，不会改整段语气。

适合什么

适合：产品名、品牌、岗位名，例如让 Atlas 始终译为指定中文。
不适合：想自动改好整段翻译，或一词多义的语境选择（那是自适应）。

  1. 先看下方预览，对照仓库 assets/glossary/product-terms.csv 了解表头和词条该怎么写。
  2. 填写你自己项目里的 GCS 桶名，一键上传样例，或上传你自己的 CSV/TSV/TMX。
  3. 用填好的 gs:// 地址创建术语表，区域建议 us-central1。
  4. 创建是后台任务；刷新清单看到 ID 后，再去文本翻译填写。

只填你能读写的桶。部署到客户环境后访问不了别人的内部测试桶；浏览器会记住这个名字。

ADAPTIVE TRANSLATION · LLM

自适应翻译

官方「自定义翻译」里的第二种方案：用 Google 的 Translation LLM，加上你的少量例句。不训练、不维护模型，所以本页没有 NMT/LLM 下拉框。

本页不是 AutoML。AutoML 要先在 Cloud Console 训练出模型 ID，再去「文本翻译」进阶填写。本页也不是术语表（锁产品名请去那一页）。没有大批训练集时，先用本页自适应即可。

和官方文档怎么对应

Cloud Translation 的自定义翻译是产品，不是再选一次模型：

  • AutoML Translation / 自定义 TLLM：导入大批语料，训练一个归你所有的模型。本 Demo 不包含训练。请打开 AutoML 官方教程 或 Translation Console，训完把模型 ID 填回文本翻译进阶。
  • 自适应翻译（本页）：底层已经是 LLM。你只要提供人工确认的双语例句，服务用这些例子定制这一次（或这个数据集）的译文。适合风格、语气、语态，以及小语料。按输入 + 输出字符计费，通常比普通 Translation LLM 更贵。

普通 Translation LLM（不带例句）在「文本翻译」页选模型即可。本页要提供的是例句，提供方式只有两种：请求内直接带句对，或先做成数据集反复用。

TRANSLATEDOCUMENT

文档翻译

接口：TranslateDocument。上传电脑里的一份小 PDF / DOCX / PPTX / XLSX，尽量保留版式，结果直接下载。

本页不能选 Translation LLM。官方 TranslateDocument 列出的内置模型只有 general/nmt；另可选已训练的 AutoML 自定义模型。LLM 和自适应请用文本 / 自适应页。

怎么用

  1. 选一份无敏感信息的小测试文件。
  2. 目标语言先用 zh-CN。
  3. 模型保持 NMT（默认）。若你已在 Console 训练过 AutoML 模型，再填模型 ID。
  4. 点“翻译并下载”。

要用术语表时，先在「术语表」页创建，并亲手填写源语言。

没有模型 ID？本页不能训练。请先到 AutoML 官方教程 和 Translation Console 完成训练。

进度和错误会显示在这里；成功时会触发下载。

BATCHTRANSLATE

批量翻译

接口：BatchTranslateText / BatchTranslateDocument。输入和输出都在 GCS。提交后只返回任务编号，不会立刻给出译文。

本页不是在线文档翻译。电脑上只有一份小文件、想马上下载，请去「文档翻译」。

怎么用

  1. 文件必须已经在你自己的 Cloud Storage，地址以 gs:// 开头。
  2. 可用下方仓库样例 assets/batch/messages.txt 一键上传，或上传自己的文件。
  3. 指定输出前缀，例如 gs://your-bucket/batch/out/。
  4. 提交后记下 operation 名称，稍后到 GCS 输出目录取结果。

输出目录也必须是这个桶（或你有写权限的另一个桶）。
